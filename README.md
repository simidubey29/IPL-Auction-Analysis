# 🏏 IPL Auction Data Analysis

## 📌 Overview

This project analyzes IPL Auction data using Python, Pandas, and Matplotlib. The project focuses on player valuations, team spending patterns, role distributions, and auction trends through data visualization.

> **Note:** This project uses a manually created dummy dataset for learning and portfolio purposes.

---

## 🛠 Tech Stack

* Python
* Pandas
* Matplotlib
* NumPy
